## 🚀 About This Repository

Welcome to my **AI Agent Engineering** learning repository!

This repository documents my hands-on journey into Generative AI, Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), Model Context Protocol (MCP), and autonomous AI agents.

I am following the Udemy course:

**AI Agent Engineering: Build Production-Ready AI Agents** by Pankaj Shukla.

Throughout this journey, I am writing Python code, experimenting with AI models, understanding agent architectures, and building practical AI-powered applications.

My goal is not just to learn the concepts but to understand how modern AI systems work and develop the skills to build intelligent, autonomous, and production-ready AI agents.

## 🎯 Learning Objectives

- Understand LLMs and how AI-powered applications work.
- Build AI assistants and conversational chatbots using Python.
- Implement conversation memory and prompt engineering.
- Integrate external tools with AI assistants.
- Build document-processing and question-answering applications.
- Understand embeddings, vector search, and RAG architectures.
- Design autonomous AI agents with planning and reasoning.
- Explore MCP and connect AI agents with external tools.
- Build multi-agent systems and agent orchestration workflows.
- Work with LangChain, LangGraph, and CrewAI.
- Develop and deploy practical AI agent applications.

## ⚙️ Getting Started

Follow these steps to run the Python examples locally.

### 1. Clone the Repository

```bash
git clone https://github.com/vinaychandel1/AI-Agent.git
```

### 2. Navigate to the Project

```bash
cd AI-Agent
```

### 3. Create a Virtual Environment

```bash
python -m venv .venv
```

### 4. Activate the Virtual Environment

**Windows PowerShell:**

```powershell
.venv\Scripts\Activate.ps1
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Configure Environment Variables

Create a `.env` file in the project root.

```env
BASE_URL=your_api_base_url
API_KEY=your_api_key
MODEL=your_model_name
```

Never commit your actual API keys or `.env` file to GitHub.

### 7. Run Your First AI Application

```bash
python Day01/hello_ai.py
```
